# Browsing

Minimal monochrome browser built on Electron (Chromium). DuckDuckGo is the default search.

Files: main.js (window + shortcuts), preload.js (safe bridge), src/ (UI), .github/workflows/build.yml (cloud build).
Shortcuts: Ctrl+T, Ctrl+W, Ctrl+R, Ctrl+L, Ctrl+Tab, Alt+Left, Alt+Right.
To build a Windows installer without a terminal, see the instructions in the chat, or double-click build-windows.bat.
